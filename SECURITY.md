# Security Policy

Kervra is pre-alpha and under active development. The application and its security controls are not yet implemented; this policy describes how to report a suspected vulnerability in the project or its repository.

Please report suspected vulnerabilities privately and avoid posting exploit details or sensitive data in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use that feature. No alternative private reporting channel has been configured; enabling private vulnerability reporting or configuring a confirmed private contact route remains pending. Do not include personal health information in a report.

There are no established supported release versions or response-time commitments yet. The maintainer will assess reports and determine next steps as the project develops.
